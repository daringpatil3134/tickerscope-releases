Quick install
Python 3.10+ Terminal w/ ANSI colour Internet (Yahoo Finance) ~50 MB disk
1
Download the .exe above and run it
The PyInstaller bundle includes Python — no separate Python install needed on Windows.
2
If Windows Defender blocks the .exe
Click More info → Run anyway. The binary is unsigned; this is expected for open-source tools built with PyInstaller.
3
Or run from source (PowerShell)
# Requires Python 3.10+
python -m venv .venv && .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python controller.py
1
Install Python 3.12 (if needed)
brew install python@3.12
2
Clone, venv, install & run
git clone <repo-url> tickerscope && cd tickerscope
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && python3 controller.py
