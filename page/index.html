NSE Intraday Scanner

Ranks NSE stocks by Reaction Factor (|Change%| × RVOL) and flags BUY CE / BUY PE setups against the Opening Range Breakout. Includes live WebSocket streaming and a browser-based analytics report.

Installation
1
Download the Windows installer
Use the download button above or the asset row in the release card.
2
Run the installer
No prerequisites needed — Python is bundled inside the .exe.
3
If Windows Defender warns you
Click More info → Run anyway. The binary is unsigned; this is expected for open-source tools built with PyInstaller.

TickerScope is currently available only for Windows.
